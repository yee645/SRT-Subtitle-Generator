# SRT 自動字幕生成與編輯工具

一套 Windows 桌面應用程式，可將影片／音訊轉錄為 SRT 字幕，或匯入現成文字稿自動對齊時間軸。內建智慧斷句、即時預覽與字幕樣式調整功能，並提供「一鍵完成」與批次處理，把生成、匯出、燒錄濃縮成一個步驟；「審片助手」則以文字審片自動標記精彩片段、冷場與重複拍攝，快速從素材挑出可用片段並輸出粗剪影片或 EDL。

### 主要功能一覽

| 功能 | 說明 | 版本 |
|------|------|------|
| 音訊轉錄字幕 | 影片／音訊自動產生逐字稿與時間軸（本地 Whisper 或 OpenAI API） | v1.0 |
| 文字稿對齊 | 貼上現成文字稿，自動對齊到真實語音時間軸 | v1.0 |
| 手動字幕模式 | 從零建立字幕、手動標記時間 | v1.1 |
| 多格式匯出／燒錄 | SRT／VTT／ASS／TXT 匯出、硬字幕燒錄進影片 | v1.1 |
| 智慧斷句／樣式調整／習慣設定 | 斷句參數、即時預覽、多組樣式記憶 | v1.0–1.2 |
| **一鍵完成＋批次處理** | 生成 → 匯出 → 燒錄一個動作完成，可多檔批次、拖檔到 exe 即處理 | **v1.3** |
| **命令列批次模式** | `python main.py 影片.mp4 ...` 免開視窗批次，適合排程 | **v1.3** |
| **審片助手** | 文字審片＋彩色時間軸，自動標記精彩／冷場／重複拍攝／口頭禪 | **v1.3** |
| **粗剪與精彩合輯輸出** | 自動跳剪粗剪影片、精彩片段合輯（Shorts 素材） | **v1.3** |
| **剪輯交付格式** | EDL（Premiere/Resolve）、HTML 審片報告、審片標記字幕、CSV、YouTube 章節 | **v1.3** |
| **審片偵測參數可調** | 精彩敏感度、自訂情緒詞、口頭禪字表、各類門檻，自動記憶 | **v1.4** |
| **轉錄快取** | 同檔案同設定免重跑語音辨識，審片後上字幕不再等第二次 | **v1.4** |
| **重複字幕修復** | 自動去除 Whisper 幻覺造成的同時間點重複字幕 | **v1.4** |

## 快速上手：一鍵完成（v1.3.0 起）

日常上字幕只需三步，全程不再跳出任何存檔對話框：

1. **選檔**：按「瀏覽...」選擇影片（可按住 Ctrl / Shift 一次選多個檔案批次處理）。
2. **勾選輸出**：在「自動化輸出」勾選要匯出的格式（SRT／VTT／ASS／TXT），需要硬字幕影片就勾「燒錄硬字幕影片」。這些勾選會被記憶，之後不必再設定。
3. **按「一鍵完成」**：程式自動完成「生成字幕 → 匯出檔案 → 燒錄影片」整條流程。

輸出規則：

- 輸出檔自動以來源檔名命名：`影片.mp4` → `影片.srt`、`影片_subtitled.mp4`。
- 預設輸出到來源檔所在資料夾；也可在「自動化輸出」指定固定的輸出資料夾。
- 同名檔已存在時自動改名為 `影片 (1).srt`，不會覆蓋舊檔。
- 批次處理時逐檔顯示進度（`[2/5] 影片B.mp4：...`），單一檔案失敗不會中斷整批，結束後會列出成功與失敗清單。
- 完成後最後一個檔案的字幕會載入清單，可直接檢視、微調後用下方按鈕重新匯出。

**批次跑「模式二：文字稿對齊」**：把每部影片的文字稿存成旁邊同名的 `.txt`（如 `演講.mp4` 配 `演講.txt`），程式會自動帶入，不必逐一貼上。

### 最快的用法：把檔案拖到 exe 圖示上

在檔案總管把一個或多個影片**直接拖曳到 `SRT-Subtitle-Generator.exe` 圖示上**，程式會依記憶的自動化設定靜默跑完整條流程，結束後以視窗回報每個檔案的輸出結果——連程式視窗都不用開。

### 命令列批次模式（進階）

不開視窗也能跑同一條自動流程，設定沿用 `config.json`（在 GUI 調好一次即可）：

```
python main.py 影片1.mp4 影片2.mp4          # 依記憶的自動化設定批次處理
python main.py --burn 影片.mp4              # 本次強制燒錄硬字幕
python main.py --formats srt,ass 影片.mp4   # 本次改匯出 SRT 與 ASS
python main.py --mode align 演講.mp4        # 文字稿對齊（文字稿放在同名 .txt）
python main.py --output-dir D:\out 影片.mp4 # 本次輸出到指定資料夾
```

命令列旗標僅影響本次執行，不會改寫記憶的設定。適合搭配排程或一次處理整批檔案。

## 審片助手：拍完快速找可用片段（v1.3.0 起）

拍完素材後來回拉時間軸找片段最耗時。審片助手改用**文字審片**——讀逐字稿遠比看影片快，且系統會先幫你標好可剪的內容：

1. 選好素材後按工具列的「**審片助手（找片段）**」，再按「開始分析」。
2. 系統轉錄素材、分析音量能量，切成講話段落並自動標記四類內容：
   - **精彩片段**（綠色）：綜合音量能量、語速、情緒詞（哇、太扯、wow…）與驚嘆句評分，達標即標記
   - **冷場**（灰色）：長時間無人聲（門檻可調，預設 2 秒）→ 預設捨棄
   - **重複拍攝**（琥珀色）：同一句話重講多次（吃螺絲重來），自動只保留最後一次 → 前面幾次預設捨棄
   - **口頭禪多**（琥珀色）：「呃、嗯、欸」等填充詞密集的段落 → 標記供複查（仍保留）
3. **一眼總覽**：視窗上方的**彩色時間軸**把整條素材畫成色帶——綠色是精彩、琥珀色待審視、灰色冷場、藍色一般內容，捨棄段以網點淡化；點任一色塊直接跳到對應段落。清單列也依同色系上底色，並顯示保留／精彩／冷場時長統計。
4. 掃一遍清單微調：雙擊或空白鍵切換保留／捨棄；「只看精彩」「只看待審視」篩選快速聚焦；關鍵字搜尋跳到講到某主題的段落。
5. 一鍵輸出（皆自動命名、不跳對話框）：

### 偵測設定：依自己的頻道風格調整（v1.4.0 起）

審片視窗的「偵測設定」區可調整所有判定參數，自動記憶、下次分析生效：

| 參數 | 說明 |
|------|------|
| **精彩敏感度**（0.2～3.0 倍） | 覺得標太少調高（>1）、標太多調低（<1） |
| **自訂情緒詞** | 附加於內建詞庫，逗號或空白分隔——加入自己頻道的口號、梗詞、產品名，讓精彩偵測貼合內容類型 |
| **口頭禪字表** | 要偵測的填充字（預設「呃嗯欸蛤齁」），依個人講話習慣增減 |
| 冷場門檻 | 無人聲多久視為冷場（預設 2 秒） |
| 段落切分停頓 | 停頓多久切成新段落（預設 1 秒） |
| 重複判定相似度 | 兩段文字多相似視為重複拍攝（預設 0.72，調高更嚴格） |

CLI 批次審片（`--review`）沿用同一組記憶的參數。

| 輸出 | 用途 |
|------|------|
| **粗剪影片（自動跳剪）** | ffmpeg 把保留段落串成一支影片，直接看粗剪效果 |
| **精彩合輯** | 只串接精彩片段——短影音（Shorts）、預告、亮點回顧素材 |
| **HTML 審片報告** | 單一檔案含彩色時間軸＋統計＋段落表，瀏覽器直接開，可傳給剪輯師 |
| **EDL（CMX3600）** | 匯入 Premiere Pro / DaVinci Resolve，時間軸即為保留段落，接著精剪 |
| **審片標記字幕（SRT）** | 與素材一起載入剪輯軟體，拉時間軸即見【精彩】【冷場】標記 |
| **CSV 片段清單** | Excel 檢視、備查、與剪輯師交接 |
| **YouTube 章節** | 複製到剪貼簿，直接貼到影片說明欄 |

**批次審片（進階）**：`python main.py --review 素材1.mp4 素材2.mp4` 可整批分析、逐檔輸出審片清單 CSV 與 HTML 報告——睡前掛整天拍的素材，隔天直接看報告挑片段。

## 一、下載與安裝

1. 前往本專案的 **Releases** 頁面，下載最新版的 `SRT-Subtitle-Generator.exe`。
2. 此為免安裝程式，下載後直接雙擊即可執行。
3. 首次執行會在程式所在資料夾自動建立 `config.json`（保存個人化設定）。

### 必要元件：ffmpeg

本程式的音訊解碼與語音轉錄皆依賴 **ffmpeg**，請務必先安裝：

1. 至 [ffmpeg 官網](https://ffmpeg.org/download.html) 下載 Windows 版。
2. 解壓縮後，將 `bin` 資料夾路徑加入系統環境變數 `PATH`。
3. 開啟命令提示字元輸入 `ffmpeg -version`，能顯示版本資訊即代表安裝成功。

未安裝 ffmpeg 時，「文字稿對齊」「本地轉錄」「字幕燒錄」「粗剪／精彩合輯輸出」與審片助手的音量能量分析皆無法使用（審片的精彩偵測會退化為純文字訊號）。

### 自動更新

本程式（v1.1.0 起）內建自動更新：

- 每次啟動時會於背景向 GitHub 檢查是否有新版本。
- 偵測到新版時會跳出視窗詢問，同意後自動下載並替換程式檔。
- 更新完成後，關閉並重新開啟程式即可套用新版。
- 無網路或連線失敗時會自動略過，不影響程式使用。

## 二、三種運作模式

### 模式一：音訊轉錄

匯入影片／音訊檔，由系統自動產生逐字稿與時間軸。轉錄引擎有兩種選擇：

- **OpenAI API**（免安裝，最簡單）
- **本地 Whisper**（免費、可離線，但需自行安裝，見下方第三節）

### 模式二：文字稿對齊

貼上現成的逐字稿，系統會借用語音辨識取得音訊中「人聲」的時間軸（會自動忽略背景音樂），再把文字稿依語音長度與停頓分配到對應的時間點，讓字幕只落在有人聲的區段。

由於改用語音辨識偵測人聲，此模式同樣需要可用的語音辨識引擎（本地 Whisper 或 OpenAI API），設定方式與模式一相同，見下方第三節。

### 模式三：手動字幕模式

不經語音辨識，從零開始手動建立字幕：按「新增字幕」逐句輸入文字與起訖時間，適合無人聲素材、歌詞字幕或需要完全手工控制的情境。建立後同樣可使用匯出與燒錄功能。

## 三、語音辨識引擎設定（模式一與模式二皆會用到）

### 方式 A：使用 OpenAI API（推薦給一般使用者）

1. 切換到「模式一」。
2. 在「轉寫設定」勾選 **改用 OpenAI API**。
3. 於「API 金鑰」欄位填入你的 OpenAI API Key。
4. 選擇生成字幕即可，無須安裝任何額外程式。

### 方式 B：使用本地 Whisper（免費、可離線）

由於本程式為輕量版 exe，**並未內建 Whisper**。exe 是封閉環境，無法直接讀取你用 pip 安裝的套件，因此需採「外部 Python」方式串接：

#### 若你尚未安裝 Whisper

1. 安裝 [Python](https://www.python.org/downloads/)（3.9 以上版本），安裝時勾選 **Add Python to PATH**。
2. 開啟命令提示字元，執行：
   ```
   pip install openai-whisper
   ```
3. 確認 ffmpeg 已安裝（見第一節）。
4. 回到本程式「轉寫設定」的 **本地 Python** 欄位：
   - 留空：程式會自動偵測系統 PATH 上的 Python。
   - 或按「瀏覽...」指向該 Python 的 `python.exe`（通常位於
     `C:\Users\你的帳號\AppData\Local\Programs\Python\PythonXX\python.exe`）。
5. 之後選擇生成字幕，程式即會透過該 Python 執行 Whisper 轉錄。

#### 若你已經安裝過 Whisper

直接在「本地 Python」欄位按「瀏覽...」，指向「當初安裝 whisper 的那個 Python 的 `python.exe`」即可，程式會自動使用它。

> 查詢 python.exe 位置：開啟命令提示字元輸入 `python -c "import sys; print(sys.executable)"`，顯示的路徑即是。

#### 本地模型選擇

「本地模型」可選 `tiny` / `base` / `small` / `medium` / `large`，模型越大越準確但越慢。模型會於首次使用時自動下載。

#### 語言選擇

「語言」欄位除 `auto`、`zh`、`en` 等代碼外，另提供 **`zh-TW`**。Whisper 本身只認 `zh` 且預設常輸出簡體中文；選擇 `zh-TW` 時，程式會以 `zh` 辨識並加繁體提示詞偏導，再自動把結果轉換為台灣繁體中文。需要繁體字幕時請選 `zh-TW`。

## 四、智慧斷句設定

「斷句設定」區塊可即時調整，兩種模式皆適用：

| 設定項目 | 說明 |
|----------|------|
| 中文單行上限 | 中文字幕單行最大字數，超過會自動斷行 |
| 英文單行上限 | 英文字幕單行最大字母數 |
| 最短秒數 | 每句字幕停留在畫面上的最短時間（過短會自動延長） |
| 最長秒數 | 每句字幕停留在畫面上的最長時間（過長會自動裁切） |
| 停頓秒數 | 音訊中靜音多久才算一次「停頓」，作為斷句與時間對齊的依據 |

斷句演算法會優先依句末標點切句，其次依句中標點切子句，避免單一字幕文字過長霸佔畫面。

## 五、字幕視覺調整

「字幕視覺調整」面板可即時設定：

- **位置**：水平 X、垂直 Y 滑桿，或使用「頂部／中部／底部」快捷鍵。
- **字型**：下拉選單內建常見中英文字型；旁邊的「...」按鈕可開啟字型選擇器，
  從系統字型中搜尋，或按「從字型檔匯入」載入自己的 `.ttf` / `.otf` 字型檔。
- **字型大小**、**文字顏色**、**邊框顏色**、**邊框寬度**。

所有調整都會即時反映在「即時字幕預覽」畫面上。

### 習慣設定（樣式組合）

「習慣設定」可儲存多組樣式組合（包含字幕樣式與斷句設定）：

- **另存新樣式**：將目前所有設定存成一組新樣式並命名。
- **更新目前樣式**：以目前設定覆寫選取中的樣式。
- **刪除**：移除選取的樣式。
- 透過下拉選單可隨時切換不同樣式組合。

## 七、生成與匯出

**建議直接使用「一鍵完成」**（見開頭「快速上手」），生成、匯出、燒錄一步到位。以下為需要逐句檢查、微調時的手動流程：

1. 選擇模式、匯入檔案（模式二另需貼上文字稿）。
2. 按「開始生成字幕」，狀態列會顯示進度。
3. 生成完成後，字幕清單會列出每一句字幕，點選任一句可在預覽畫面中檢視，雙擊可編輯。
4. 按「匯出 SRT／VTT／ASS／TXT」選擇儲存位置輸出字幕檔，或按「燒錄字幕到影片」輸出硬字幕影片。

## 八、常見問題

**Q：點「開始生成字幕」後出現「找不到 ffmpeg」？**
A：請依第一節安裝 ffmpeg 並加入系統 PATH。

**Q：本地轉錄出現「找不到可用的本地 Whisper」？**
A：請依第三節方式 B 安裝 Whisper，並在「本地 Python」欄位指向正確的 python.exe，或改用 OpenAI API 模式。

**Q：視窗內容顯示不下？**
A：視窗可自由縮放，內容超出時可使用右側／底部捲軸，或用滑鼠滾輪捲動。

**Q：字幕斷句太長或太短？**
A：於「斷句設定」調整單行字數上限與秒數限制後重新生成。

**Q：「一鍵完成」的檔案輸出到哪裡？**
A：預設輸出到來源影片所在的資料夾，檔名沿用來源檔名（如 `影片.srt`、`影片_subtitled.mp4`）。想集中輸出到固定資料夾，可在「自動化輸出」的「輸出資料夾」指定。同名檔不會被覆蓋，會自動加上 `(1)` 流水號。

**Q：把檔案拖到 exe 圖示上沒有反應？**
A：拖曳執行採用「自動化輸出」記憶的設定，請先開啟程式在「自動化輸出」勾選至少一種匯出格式（或燒錄），關閉程式後再拖曳。處理需要時間（轉錄與燒錄），完成後才會跳出結果視窗。

**Q：審片助手的「精彩片段」是怎麼判定的？標太多／太少怎麼辦？**
A：綜合四種訊號評分——說話音量能量、語速、情緒詞（哇、太扯、wow…）與驚嘆句，達門檻即標記。標太少請到「偵測設定」把**精彩敏感度**調高（如 1.5），標太多就調低（如 0.7）；也可在**自訂情緒詞**加入自己頻道常用的口號與梗詞，讓判定更貼合內容。設定會自動記憶。

**Q：同一支影片轉錄過了，換個功能又要重新等辨識？**
A：v1.4.0 起內建轉錄快取：同一檔案且轉寫設定相同時自動重用先前結果（例如審片分析完再一鍵上字幕，第二次瞬間完成）。快取存於程式資料夾的 `transcribe_cache/`，自動限量清理；不需要時可在「轉寫設定」取消勾選「重用轉錄快取」。

**Q：轉錄結果在同一時間點出現多句重複字幕？**
A：這是 Whisper 遇到靜音或背景音樂時的已知現象（幻覺迴圈），v1.4.0 已加入三層自動去重防護。若仍遇到，可回報 issue 並附上來源音訊特徵（如長靜音、純音樂段）。

**Q：審片助手輸出的 EDL 怎麼用？**
A：在 Premiere Pro 選「檔案 → 讀入」、DaVinci Resolve 選「File → Import → Timeline」載入 `.edl`，再連結原始素材，時間軸就是保留段落的順剪，可直接開始精剪。

**Q：粗剪影片／精彩合輯輸出後聲音或畫面不同步？**
A：粗剪採重新編碼（libx264＋AAC）確保剪點精準，一般不會不同步；若來源影片編碼特殊，建議改用 EDL 進剪輯軟體處理。
