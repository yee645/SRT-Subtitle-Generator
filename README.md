# SRT 自動字幕生成與編輯工具

Windows 桌面程式：把影片／音訊轉成 SRT 字幕，或把現成文字稿自動對齊到時間軸；
校對、樣式、匯出與燒錄一次完成，並附上片前的健檢與剪輯小工具。

## 主要功能

- **字幕**：〔語音轉寫〕（本地 Whisper 或 OpenAI API）、〔文字稿對齊〕、〔手動輸入〕；
  智慧斷句、即時預覽、樣式調整；匯出 SRT／VTT／ASS／TXT 或燒錄硬字幕；可匯入既有字幕。
- **審片與剪輯**：審片助手自動標記精彩片段、冷場與重複拍攝，輸出粗剪影片或 EDL；
  剪停頓、剪重複片段、短片自動選段、音樂節拍分析。
- **健檢中心**：爆音、音量、底噪、畫質、字幕品質、開場、節奏、廣告友善度、發佈資訊、
  封面、章節等一次跑完，可修的項目旁邊就有修復按鈕。
- **成品加工**：配樂助手（背景音樂自動閃避人聲）、品牌套版（片頭片尾與浮水印）、
  封面候選、多語字幕包。
- **翻譯**：即時查譯；螢幕畫面翻譯——框選任何一塊畫面在本機辨識後翻譯，
  熱鍵 Ctrl+Alt+F8（v2.3 起）。

## 3.0：新介面（真的播放器與時間軸）

3.0.0 起有兩個介面，功能一樣：

- **新介面（Qt，3.0 起）**：字幕疊在真的影片畫面上預覽；時間軸看得到縮圖、波形、字幕塊與要剪掉的段落，
  拖邊改時間、剪點可單獨停用；可以加 B-roll、圖片、音樂與轉場，畫面調整即時預覽，整條時間軸存成專案檔；
  在程式裡〔下載並安裝〕更新。
- **一般版（原本的視窗）**：照樣能用、照樣自動更新。

兩邊都是四個階段頁籤，順序就是做一支影片的順序：

| 頁籤 | 裡面有什麼 |
|------|-----------|
| **① 素材與剪輯** | 選檔、審片助手、音訊轉影片、批次一鍵完成 |
| **② 字幕** | 生成字幕、逐句校對、翻譯、樣式（新介面：播放器＋時間軸、剪點） |
| **③ 健檢中心** | 各項健檢一次跑完，可修的直接修 |
| **④ 輸出與發佈** | 輸出設定＋完成輸出＋逐格式匯出、配樂、品牌套版 |

3.0 加了什麼、東西在新介面的哪裡，見 **[3.0 新功能介紹](docs/WHATS_NEW_3.0.md)**。

## 快速上手

1. 到 [Releases](../../releases) 下載：
   - 新介面：`SRT-Subtitle-Generator-Qt-v<版本>-win64.zip`，解壓後執行資料夾裡的 `SRT-Subtitle-Generator-Qt.exe`；
   - 一般版：`SRT-Subtitle-Generator.exe`，單一檔案、雙擊執行。已經在用一般版的話，更新到 3.0 之後它會提示一鍵裝好新介面。
   兩個都免安裝。
2. 選影片 → 生成字幕 → 校對 → 完成輸出。
3. 多支影片可以用批次一鍵完成整批跑完；一般版也可以直接把檔案拖到 exe 圖示上。

需要 **ffmpeg**：程式偵測不到時會提供一鍵安裝（免管理員權限）。
程式啟動時會自動檢查更新。從原始碼跑：`pip install PySide6` 後 `python main.py`（一般版加 `--tk`）；
命令列批次模式（`python main.py 影片.mp4`）見使用說明。

完整操作、設定、命令列參數與常見問題見 **[使用說明](docs/USER_GUIDE.md)**；
每一版加了什麼、各功能怎麼用，見 **[功能詳解](docs/FEATURES.md)**。

## 系統需求

- Windows 10 / 11（新介面的 zip 約 56 MB，解開約 129 MB）
- 必要：ffmpeg
- 從原始碼跑新介面：PySide6
- 選用：Python + openai-whisper（本地轉錄）、OpenAI API 金鑰（API 轉錄、翻譯）
