# SRT 自動字幕生成與編輯工具

Windows 桌面程式：把影片／音訊轉成 SRT 字幕，或把現成文字稿自動對齊到時間軸；
校對、樣式、匯出與燒錄一次完成，並附上片前的健檢與剪輯小工具。

## 主要功能

- **字幕**：〔語音轉寫〕（本地 Whisper 或 OpenAI API）、〔文字稿對齊〕、〔手動輸入〕；
  智慧斷句、即時預覽、樣式調整；匯出 SRT／VTT／ASS／TXT 或燒錄硬字幕；可匯入既有字幕。
- **審片與剪輯**：審片助手自動標記精彩片段、冷場與重複拍攝，輸出粗剪影片或 EDL；
  剪停頓、剪重複片段、短片自動選段、音樂節拍分析。
- **健檢中心**：爆音、音量、底噪、畫質、字幕品質、開場、節奏、廣告友善度、發佈資訊、
  封面、章節等一次跑完，可修的項目旁邊就有修復按鈕。
- **成品加工**：配樂助手（背景音樂自動閃避人聲）、品牌套版（片頭片尾與浮水印）、
  封面候選、多語字幕包。
- **翻譯**：即時查譯；螢幕畫面翻譯——框選任何一塊畫面在本機辨識後翻譯，
  熱鍵 Ctrl+Alt+F8（v2.3 起）。

每一版加了什麼、各功能怎麼用，見 **[功能詳解](docs/FEATURES.md)**。

## 介面

主視窗是四個階段頁籤，順序就是做一支影片的順序：

| 頁籤 | 裡面有什麼 |
|------|-----------|
| **① 素材與剪輯** | 選檔、匯入既有字幕、審片助手、剪停頓（依字幕）、剪重複片段 |
| **② 字幕** | 設定、主動作與字幕清單、樣式與即時預覽 |
| **③ 健檢中心** | 各項健檢一次跑完，可修的直接修 |
| **④ 輸出與發佈** | 輸出設定＋完成輸出＋逐格式匯出、配樂助手、品牌套版 |

## 快速上手

1. 到 [Releases](../../releases) 下載最新的 `SRT-Subtitle-Generator.exe`，免安裝、雙擊執行。
2. 選影片 → 按〔開始生成字幕〕→ 校對 → 按〔完成輸出（依輸出設定）〕。
3. 多支影片可一次選取，用〔批次一鍵完成〕整批跑完；也可以直接把檔案拖到 exe 圖示上。

需要 **ffmpeg**：程式偵測不到時會提供「自動安裝 ffmpeg」按鈕（免管理員權限）。
程式啟動時會自動檢查更新。命令列批次模式（`python main.py 影片.mp4`）見使用說明。

完整操作、設定、命令列參數與常見問題見 **[使用說明](docs/USER_GUIDE.md)**。
