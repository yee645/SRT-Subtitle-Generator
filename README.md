# SRT 自動字幕生成與編輯工具

一套 Windows 桌面應用程式，可將影片／音訊轉錄為 SRT 字幕，或匯入現成文字稿自動對齊時間軸。內建智慧斷句、即時預覽與字幕樣式調整功能，並提供「一鍵完成」與批次處理，把生成、匯出、燒錄濃縮成一個步驟；「審片助手」則以文字審片自動標記精彩片段、冷場與重複拍攝，快速從素材挑出可用片段並輸出粗剪影片或 EDL。

### 主要功能一覽

| 功能 | 說明 | 版本 |
|------|------|------|
| 音訊轉錄字幕 | 影片／音訊自動產生逐字稿與時間軸（本地 Whisper 或 OpenAI API） | v1.0 |

## 快速上手：一鍵完成（v1.3.0 起）

日常上字幕只需三步，全程不再跳出任何存檔對話框：

1. **選檔**：按「瀏覽...」選擇影片（可按住 Ctrl / Shift 一次選多個檔案批次處理）。
2. **勾選輸出**：在「自動化輸出」勾選要匯出的格式（SRT／VTT／ASS／TXT），需要硬字幕影片就勾「燒錄硬字幕影片」。這些勾選會被記憶，之後不必再設定。
3. **按「一鍵完成」**：程式自動完成「生成字幕 → 匯出檔案 → 燒錄影片」整條流程。

輸出規則：

- 輸出檔自動以來源檔名命名：`影片.mp4` → `影片.srt`、`影片_subtitled.mp4`。
- 預設輸出到來源檔所在資料夾；也可在「自動化輸出」指定固定的輸出資料夾。
- 同名檔已存在時自動改名為 `影片 (1).srt`，不會覆蓋舊檔。
- 批次處理時逐檔顯示進度（`[2/5] 影片B.mp4：...`），單一檔案失敗不會中斷整批，結束後會列出成功與失敗清單。
- 完成後最後一個檔案的字幕會載入清單，可直接檢視、微調後用下方按鈕重新匯出。

**批次跑「模式二：文字稿對齊」**：把每部影片的文字稿存成旁邊同名的 `.txt`（如 `演講.mp4` 配 `演講.txt`），程式會自動帶入，不必逐一貼上。

### 最快的用法：把檔案拖到 exe 圖示上

在檔案總管把一個或多個影片**直接拖曳到 `SRT-Subtitle-Generator.exe` 圖示上**，程式會依記憶的自動化設定靜默跑完整條流程，結束後以視窗回報每個檔案的輸出結果——連程式視窗都不用開。

### 命令列批次模式（進階）

不開視窗也能跑同一條自動流程，設定沿用 `config.json`（在 GUI 調好一次即可）：

```
python main.py 影片1.mp4 影片2.mp4          # 依記憶的自動化設定批次處理
python main.py --burn 影片.mp4              # 本次強制燒錄硬字幕
python main.py --formats srt,ass 影片.mp4   # 本次改匯出 SRT 與 ASS
python main.py --mode align 演講.mp4        # 文字稿對齊（文字稿放在同名 .txt）
python main.py --output-dir D:\out 影片.mp4 # 本次輸出到指定資料夾
```

命令列旗標僅影響本次執行，不會改寫記憶的設定。適合搭配排程或一次處理整批檔案。

## 審片助手：拍完快速找可用片段（v1.3.0 起）

拍完素材後來回拉時間軸找片段最耗時。審片助手改用**文字審片**——讀逐字稿遠比看影片快，且系統會先幫你標好可剪的內容：

1. 選好素材後按工具列的「**審片助手（找片段）**」，再按「開始分析」。
2. 系統轉錄素材、分析音量能量，切成講話段落並自動標記四類內容：
   - **精彩片段**（綠色）：綜合音量能量、語速、情緒詞（哇、太扯、wow…）與驚嘆句評分，達標即標記
   - **冷場**（灰色）：長時間無人聲（門檻可調，預設 2 秒）→ 預設捨棄
   - **重複拍攝**（琥珀色）：同一句話重講多次（吃螺絲重來），自動只保留最後一次 → 前面幾次預設捨棄
   - **口頭禪多**（琥珀色）：「呃、嗯、欸」等填充詞密集的段落 → 標記供複查（仍保留）
3. **一眼總覽**：視窗上方的**彩色時間軸**把整條素材畫成色帶——綠色是精彩、琥珀色待審視、灰色冷場、藍色一般內容，捨棄段以網點淡化；點任一色塊直接跳到對應段落。清單列也依同色系上底色，並顯示保留／精彩／冷場時長統計。
4. 掃一遍清單微調：雙擊或空白鍵切換保留／捨棄；「只看精彩」「只看待審視」篩選快速聚焦；關鍵字搜尋跳到講到某主題的段落。

### 偵測設定：依自己的頻道風格調整（v1.4.0 起）

審片視窗的「偵測設定」區可調整所有判定參數，自動記憶、下次分析生效：

| 參數 | 預設值 | 可調範圍 | 調高會怎樣 | 調低會怎樣 |
|------|--------|----------|------------|------------|
| **精彩敏感度** | 1.0 倍 | 0.2～3.0 | 更多段落被標成精彩（綠色變多） | 判定更嚴格，只有反應最大的段落才標精彩 |
| **自訂情緒詞** | （空） | 自由輸入 | 加入的詞出現時更容易被判定精彩 | — |
| **口頭禪字表** | 呃嗯欸蛤齁 | 自由輸入 | 更多字被算進口頭禪密度 | 少算一些字，避免正常用字被誤判 |
| **冷場門檻** | 2 秒 | 0.5～10 | 更久的安靜才算冷場（保留較多安靜片段） | 較短的安靜就標記冷場，剪得更緊湊 |
| **段落切分停頓** | 1 秒 | 0.4～5 | 段落被切得更細（停頓稍長就分段） | 段落較長，只有明顯停頓才分段 |
| **重複判定相似度** | 0.72 | 0.5～0.95 | 判定更嚴格，只有幾乎一字不差才算重複拍攝 | 較寬鬆，措辭略有出入也會歸為同一次重講 |
| **口頭禪密度門檻** | 0.08 | 0.02～0.5 | 口頭禪要非常密集才標記「口頭禪多」 | 稍微多一點口頭禪就會被標記供複查 |
| **章節最短長度** | 60 秒 | 10～600 | YouTube 章節切得更粗（章節數變少） | 章節切得更細（章節數變多） |
| **精彩訊號權重**（v1.7.0 起） | 各 1.0 | 0～3 | 該訊號對精彩判定的影響變大 | 影響變小；調到 0 完全停用該訊號 |

**精彩訊號權重**是四個獨立的旋鈕（音量、語速、情緒詞、驚嘆句），與「精彩敏感度」的差別：敏感度是整體門檻的高低，權重則決定**由哪些訊號來判定**。例如：

- 教學型影片語調平穩、很少驚呼 → 情緒詞 0.5、驚嘆句 0.5、音量 1.5：讓「講到重點自然提高音量」成為主要依據
- 遊戲實況激動時刻靠喊出來 → 音量 2.0、語速 1.5：抓住尖叫與連珠炮反應
- 想純靠內容文字判定（如錄音環境音量不穩） → 音量 0：完全忽略音量訊號

拿不準怎麼調時，建議的操作順序：**先用預設值跑一次分析 → 看彩色時間軸的結果 → 只調一個最不滿意的參數 → 重新分析比較差異**，而不是一次改動多個參數，比較容易看出哪個設定造成了影響。

#### 情境範例：三種常見素材類型的起始設定

以下是三種常見頻道／素材類型可以直接套用的起始值（仍可再依實際結果微調）：

| 情境 | 精彩敏感度 | 冷場門檻 | 重複判定相似度 | 說明 |
|------|-----------|----------|----------------|------|
| **Vlog／生活紀錄**（講話反應平緩，很少大喊大叫） | 1.3～1.5 | 2～3 秒 | 0.72（預設） | 語調變化小，敏感度調高才抓得到「相對」精彩的段落 |
| **遊戲實況／開箱剪輯**（情緒起伏大、常有驚呼） | 0.8～1.0（預設） | 1.5 秒 | 0.65（放寬） | 反應本來就多，用預設或略降即可；玩家常常重講同句台詞，相似度放寬更容易抓到重複 |
| **教學／知識型影片**（語速平穩、內容重於情緒） | 1.0（預設） | 3～4 秒（拉長） | 0.8（收緊，避免正常重述被誤判） | 錄影中常有思考停頓，冷場門檻拉長避免正常換氣被剪掉；教學常會刻意重複重點，相似度收緊避免誤刪 |

CLI 批次審片（`--review`）沿用同一組記憶的參數。

### Shorts 直式短片輸出（v1.5.0 起）

橫式素材重剪成 Shorts／Reels／TikTok 最花時間。審片助手輸出區的「**直式短片**」列可把任意段落一鍵轉成 9:16（1080x1920）直式影片：

1. 在段落清單**選取要輸出的段落**（Ctrl／Shift 可多選）；不選取則自動輸出所有**精彩片段**。
2. 選版式：
   - **裁切**：以「焦點」滑調（0 最左、0.5 置中、1 最右）決定取景位置，適合人物固定在畫面某側
   - **模糊背景**：完整畫面置中、上下以放大模糊的原畫面填滿，畫面資訊不損失
3. 可勾「**燒錄字幕**」（沿用你的字幕視覺樣式，時間軸自動平移）與「**響度正規化**」。
4. 按「輸出直式短片」，每段各輸出一支 `素材_短片01.mp4`，逐支顯示進度。

版式、焦點等設定會自動記憶。

**「焦點」怎麼調（範例）：** 先用 0.5（置中）輸出一支試看——人物若被裁到左邊畫面外，調小到 0.2～0.3；被裁到右邊畫面外，調大到 0.7～0.8。單人固定坐在鏡頭前的講話素材通常 0.5 就夠用；若人物在畫面中會左右走動，改用「模糊背景」版式較保險，不必為了裁切焦點反覆試錯。

### 響度正規化：告別影片太小聲（v1.5.0 起）

YouTube 會把超過 -14 LUFS 的音訊自動調小，但**太小聲的不會被調大**——錄音偏小聲的影片上傳後會一直小聲。解法：

- 在「自動化輸出」勾選「**燒錄時響度正規化**」，目標值預設 **-14 LUFS**（YouTube 標準，可調 -30～-8）。
- 之後「一鍵完成」與「燒錄字幕到影片」輸出的影片都會先量測實際響度、再線性校正到目標值（兩階段處理，比單次動態調整更精準、音質更好）。
- 直式短片輸出也有獨立的「響度正規化」勾選。
- CLI：`--loudnorm`／`--no-loudnorm` 可覆寫本次設定。

**目標值怎麼選（範例）：**

| 目標值 | 適合情境 |
|--------|----------|
| **-14 LUFS**（預設） | 一般 YouTube 影片，不確定要選什麼就用這個 |
| **-11～-13 LUFS** | 音樂／節奏感強的內容，想要比平台基準略響亮一點 |
| **-16 LUFS** | Podcast、純口說訪談，避免長時間收聽顯得刺耳 |
| **-19～-23 LUFS** | 供電視或需符合廣播響度規範的交付素材 |

不確定自己影片目前多大聲也沒關係——這個功能會自動先量測，你只需要決定「想要多大聲」這個目標值即可。

| 輸出 | 用途 |
|------|------|
| **粗剪影片（自動跳剪）** | ffmpeg 把保留段落串成一支影片，直接看粗剪效果 |
| **精彩合輯** | 只串接精彩片段——短影音（Shorts）、預告、亮點回顧素材 |
| **HTML 審片報告** | 單一檔案含彩色時間軸＋統計＋段落表，瀏覽器直接開，可傳給剪輯師 |
| **EDL（CMX3600）** | 匯入 Premiere Pro / DaVinci Resolve，時間軸即為保留段落，接著精剪 |
| **審片標記字幕（SRT）** | 與素材一起載入剪輯軟體，拉時間軸即見【精彩】【冷場】標記 |
| **CSV 片段清單** | Excel 檢視、備查、與剪輯師交接 |
| **YouTube 章節** | 智慧合併成合理粒度（見下），複製即貼影片說明欄 |

**YouTube 章節智慧合併（v1.6.0 起）**：章節不會一段一章——只在大停頓（剪掉的冷場處）且目前章節已達「**章節最短長度**」（偵測設定可調，預設 60 秒）時才切新章，首章固定 0:00。覺得章節太細調大、太粗調小。

**批次審片（進階）**：`python main.py --review 素材1.mp4 素材2.mp4` 可整批分析、逐檔輸出審片清單 CSV 與 HTML 報告——睡前掛整天拍的素材，隔天直接看報告挑片段。

**多檔審片彙總（v1.7.0 起）**：批次審片兩支以上素材時，自動另輸出「**審片彙總.html**」與「**審片彙總_精彩TopN.csv**」——整批素材的精彩片段**跨檔**依分數排序，並附各素材統計對照表（總長、保留、精彩段數、冷場、口頭禪）。一天拍 20 支素材，隔天打開彙總頁就知道「這批裡最值得用的前 10 段」在哪支的第幾分鐘，不必逐檔比較。Top N 段數可在 `config.json` 的 `review.batch_top_n` 調整（3～50，預設 10）。

## 一、下載與安裝

1. 前往本專案的 **Releases** 頁面，下載最新版的 `SRT-Subtitle-Generator.exe`。
2. 此為免安裝程式，下載後直接雙擊即可執行。
3. 首次執行會在程式所在資料夾自動建立 `config.json`（保存個人化設定）。

### 必要元件：ffmpeg

本程式的音訊解碼與語音轉錄皆依賴 **ffmpeg**，請務必先安裝：

1. 至 [ffmpeg 官網](https://ffmpeg.org/download.html) 下載 Windows 版。
2. 解壓縮後，將 `bin` 資料夾路徑加入系統環境變數 `PATH`。
3. 開啟命令提示字元輸入 `ffmpeg -version`，能顯示版本資訊即代表安裝成功。

未安裝 ffmpeg 時，「文字稿對齊」「本地轉錄」「字幕燒錄」「粗剪／精彩合輯輸出」與審片助手的音量能量分析皆無法使用（審片的精彩偵測會退化為純文字訊號）。

### 自動更新

本程式（v1.1.0 起）內建自動更新：

- 每次啟動時會於背景向 GitHub 檢查是否有新版本。
- 偵測到新版時會跳出視窗詢問，同意後自動下載並替換程式檔。
- 更新完成後，關閉並重新開啟程式即可套用新版。
- 無網路或連線失敗時會自動略過，不影響程式使用。

## 二、三種運作模式

### 模式一：音訊轉錄

匯入影片／音訊檔，由系統自動產生逐字稿與時間軸。轉錄引擎有兩種選擇：

- **OpenAI API**（免安裝，最簡單）
- **本地 Whisper**（免費、可離線，但需自行安裝，見下方第三節）

### 模式二：文字稿對齊

貼上現成的逐字稿，系統會借用語音辨識取得音訊中「人聲」的時間軸（會自動忽略背景音樂），再把文字稿依語音長度與停頓分配到對應的時間點，讓字幕只落在有人聲的區段。

由於改用語音辨識偵測人聲，此模式同樣需要可用的語音辨識引擎（本地 Whisper 或 OpenAI API），設定方式與模式一相同，見下方第三節。

### 模式三：手動字幕模式

不經語音辨識，從零開始手動建立字幕：按「新增字幕」逐句輸入文字與起訖時間，適合無人聲素材、歌詞字幕或需要完全手工控制的情境。建立後同樣可使用匯出與燒錄功能。

---

## 三、語音辨識引擎設定（模式一與模式二皆會用到）

### 方式 A：使用 OpenAI API（推薦給一般使用者）

1. 切換到「模式一」。
2. 在「轉寫設定」勾選 **改用 OpenAI API**。
3. 於「API 金鑰」欄位填入你的 OpenAI API Key。
4. 選擇生成字幕即可，無須安裝任何額外程式。

### 方式 B：使用本地 Whisper（免費、可離線）

由於本程式為輕量版 exe，**並未內建 Whisper**。exe 是封閉環境，無法直接讀取你用 pip 安裝的套件，因此需採「外部 Python」方式串接：

#### 若你尚未安裝 Whisper

1. 安裝 [Python](https://www.python.org/downloads/)（3.9 以上版本），安裝時勾選 **Add Python to PATH**。
2. 開啟命令提示字元，執行：
   ```
   pip install openai-whisper
   ```
3. 確認 ffmpeg 已安裝（見第一節）。
4. 回到本程式「轉寫設定」的 **本地 Python** 欄位：
   - 留空：程式會自動偵測系統 PATH 上的 Python。
   - 或按「瀏覽...」指向該 Python 的 `python.exe`（通常位於
     `C:\Users\你的帳號\AppData\Local\Programs\Python\PythonXX\python.exe`）。
5. 之後選擇生成字幕，程式即會透過該 Python 執行 Whisper 轉錄。

#### 若你已經安裝過 Whisper

直接在「本地 Python」欄位按「瀏覽...」，指向「當初安裝 whisper 的那個 Python 的 `python.exe`」即可，程式會自動使用它。

> 查詢 python.exe 位置：開啟命令提示字元輸入 `python -c "import sys; print(sys.executable)"`，顯示的路徑即是。

#### 本地模型選擇

「本地模型」可選 `tiny` / `base` / `small` / `medium` / `large`，模型越大越準確但越慢。模型會於首次使用時自動下載。

#### 語言選擇

「語言」欄位除 `auto`、`zh`、`en` 等代碼外，另提供 **`zh-TW`**。Whisper 本身只認 `zh` 且預設常輸出簡體中文；選擇 `zh-TW` 時，程式會以 `zh` 辨識並加繁體提示詞偏導，再自動把結果轉換為台灣繁體中文。需要繁體字幕時請選 `zh-TW`。

## 四、智慧斷句設定

「斷句設定」區塊可即時調整，兩種模式皆適用：

| 設定項目 | 說明 | 調整範例 |
|----------|------|----------|
| 中文單行上限 | 中文字幕單行最大字數，超過會自動斷行 | 手機直向觀看字幕常顯太長時，調小到 14～16 字；橫向大螢幕可放寬到 20 字以上 |
| 英文單行上限 | 英文字幕單行最大字母數 | 同上邏輯，手機觀看建議 30～36 字母 |
| 最短秒數 | 每句字幕停留在畫面上的最短時間（過短會自動延長） | 觀眾反映字幕一閃即逝時調大（如 1.5 秒） |
| 最長秒數 | 每句字幕停留在畫面上的最長時間（過長會自動裁切） | 長句被硬切太短時可調大（如 6～8 秒），但避免整段影片只有幾句字幕 |
| 停頓秒數 | 音訊中靜音多久才算一次「停頓」，作為斷句與時間對齊的依據 | 講話語速快、停頓短的內容（如遊戲實況）可調小（0.3～0.5 秒）讓斷句更即時；語速慢、常有思考停頓的內容可調大避免斷句過於破碎 |

斷句演算法會優先依句末標點切句，其次依句中標點切子句，避免單一字幕文字過長霸佔畫面。不確定該調多少時，先用預設值生成一次字幕，看實際效果哪裡不順眼（太長／太短／停留太久／太快消失）再針對性調整，比一開始就大幅更動更容易抓到合適的數值。

## 五、字幕視覺調整

「字幕視覺調整」面板可即時設定：

- **位置**：水平 X、垂直 Y 滑桿，或使用「頂部／中部／底部」快捷鍵。
- **字型**：下拉選單內建常見中英文字型；旁邊的「...」按鈕可開啟字型選擇器，
  從系統字型中搜尋，或按「從字型檔匯入」載入自己的 `.ttf` / `.otf` 字型檔。
- **字型大小**、**文字顏色**、**邊框顏色**、**邊框寬度**。
- **重點字上色**（v1.6.0 起）：勾選後填入詞彙（逗號或空白分隔，如自己頻道的產品名、「免費」「限時」等），燒錄影片與匯出 ASS 時這些詞會自動換色強調（預設金黃、可選色）——CapCut 風格的重點標記，免逐句手動處理。SRT／VTT 純文字輸出不受影響。

  **範例：** 帶貨直播剪輯常見句子「這個現在**免費**送，數量**限時**搶購」，只要在重點字欄位填入 `免費, 限時`，之後每一句字幕只要出現這兩個詞就自動變色，不必逐句手動上色；詞彙用逗號或空白分開即可一次填多個，長詞（如「破盤價」）會優先於短詞比對，不會被短詞截斷。想要不同影片用不同顏色（例如促銷用紅色、重點用金黃），改變「重點字顏色」即可，設定會隨樣式一起記憶。

- **動態字幕**（v1.7.0 起）：逐字動畫字幕，於燒錄影片與 ASS 匯出時生效，兩種模式：
  - **逐字上色（卡拉OK）**：整句顯示在畫面上，講到哪個字、哪個字就換色（顏色沿用「重點字顏色」）——觀眾的視線跟著語音走
  - **單字彈出**：畫面上只顯示當前講到的字詞，並帶輕微放大彈出動畫——Shorts／Reels／TikTok 最常見的字幕版式，搭配大字級（例如 48 以上）與畫面中央位置效果最好
  - 需要逐字時間軸，因此**只在「模式一：音訊轉錄」產生的字幕上生效**；手動字幕、文字稿對齊或編輯過的句子自動退回一般整句顯示，不會出錯
  - 審片助手輸出的直式短片若勾「燒錄字幕」，同樣套用此模式——單字彈出＋直式短片就是現成的 Shorts 成品

所有調整（含重點字上色，v1.6.1 起）都會即時反映在「即時字幕預覽」畫面上，改詞彙或顏色不必先燒錄就能看到效果（動態字幕的逐字動畫屬於影片時間軸效果，預覽維持整句顯示，實際效果以燒錄輸出為準）。

### 習慣設定（樣式組合）

「習慣設定」可儲存多組樣式組合（包含字幕樣式與斷句設定）：

- **另存新樣式**：將目前所有設定存成一組新樣式並命名。
- **更新目前樣式**：以目前設定覆寫選取中的樣式。
- **刪除**：移除選取的樣式。
- 透過下拉選單可隨時切換不同樣式組合。

## 七、生成與匯出

**建議直接使用「一鍵完成」**（見開頭「快速上手」），生成、匯出、燒錄一步到位。以下為需要逐句檢查、微調時的手動流程：

1. 選擇模式、匯入檔案（模式二另需貼上文字稿）。
2. 按「開始生成字幕」，狀態列會顯示進度。
3. 生成完成後，字幕清單會列出每一句字幕，點選任一句可在預覽畫面中檢視，雙擊可編輯。
4. **校對**：同一個錯字整集重複出現時（人名、產品名、同音字），按「**尋找取代**」（v1.7.0 起）一次修正——「找下一個」逐句檢視、「取代目前」逐句確認、「全部取代」一鍵修完並回報次數；對話框開著仍可操作清單。
5. 按「匯出 SRT／VTT／ASS／TXT」選擇儲存位置輸出字幕檔，或按「燒錄字幕到影片」輸出硬字幕影片。

## 八、參數設定速查表

程式裡可調的參數分散在不同面板，這裡整理成一張總表方便查找「這個參數在哪、預設多少、什麼時候該調」。每一項都會自動記憶在 `config.json`，調過一次之後不必重設。

| 參數 | 位置 | 預設值 | 什麼時候該調 |
|------|------|--------|--------------|
| 中文／英文單行上限 | 斷句設定 | 中文 18 字 | 手機直向觀看字幕顯得太長、太占畫面 → 調小 |
| 最短／最長秒數 | 斷句設定 | 依模式而定 | 字幕一閃即逝 → 調大最短秒數；長句被切太碎 → 調大最長秒數 |
| 停頓秒數 | 斷句設定 | 依模式而定 | 語速快的內容斷句太慢／太粗 → 調小；語速慢的內容斷句太破碎 → 調大 |
| 精彩敏感度 | 審片助手／偵測設定 | 1.0 | 精彩片段標太少 → 調高；標太多、雜訊太多 → 調低 |
| 自訂情緒詞 | 審片助手／偵測設定 | 空 | 頻道有固定口頭禪、產品名、梗詞想被判定為精彩訊號 → 填入 |
| 冷場門檻 | 審片助手／偵測設定 | 2 秒 | 教學類常有思考停頓被誤判冷場 → 調大；想剪更緊湊 → 調小 |
| 重複判定相似度 | 審片助手／偵測設定 | 0.72 | 常有重複拍攝沒被抓到 → 調低；正常重述被誤判重複 → 調高 |
| 章節最短長度 | 審片助手／偵測設定 | 60 秒 | YouTube 章節切太細 → 調大；切太粗 → 調小 |
| 響度正規化目標值 | 自動化輸出 | -14 LUFS | 一般影片用預設；音樂類想更響亮 → -11～-13；口說類想更柔和 → -16 |
| 直式短片焦點 | 審片助手／直式短片 | 0.5（置中） | 人物被裁到畫面外 → 往人物方向調（偏左調小、偏右調大） |
| 重點字詞彙／顏色 | 字幕視覺調整 | 空／金黃 | 想強調促銷字眼、口號、產品名時填入詞彙並選喜歡的顏色 |
| 精彩訊號權重 | 審片助手／偵測設定 | 各 1.0 | 想指定「靠什麼判定精彩」：教學型調低情緒詞、遊戲實況調高音量；0＝停用該訊號 |
| 動態字幕模式 | 字幕視覺調整 | 無（整句） | 做 Shorts 想要逐字換色或單字彈出動畫時切換；需模式一轉錄的字幕 |
| 彙總 Top N | config.json `review.batch_top_n` | 10 | 批次審片素材很多、想看更多候選片段 → 調大 |

**建議的調參心法：** 先用預設值跑一次（生成字幕或審片分析），實際看結果哪裡不滿意，再針對那一項參數做小幅調整、重新跑一次比較差異——不要一次改動多個參數，否則很難判斷是哪個設定造成的變化。上面「偵測設定」小節另有依頻道類型（Vlog／遊戲實況／教學型）整理的起始值組合可直接套用。

## 九、常見問題

**Q：點「開始生成字幕」後出現「找不到 ffmpeg」？**
A：請依第一節安裝 ffmpeg 並加入系統 PATH。

**Q：本地轉錄出現「找不到可用的本地 Whisper」？**
A：請依第三節方式 B 安裝 Whisper，並在「本地 Python」欄位指向正確的 python.exe，或改用 OpenAI API 模式。

**Q：視窗內容顯示不下？**
A：視窗可自由縮放，內容超出時可使用右側／底部捲軸，或用滑鼠滾輪捲動。

**Q：字幕斷句太長或太短？**
A：於「斷句設定」調整單行字數上限與秒數限制後重新生成。

**Q：「一鍵完成」的檔案輸出到哪裡？**
A：預設輸出到來源影片所在的資料夾，檔名沿用來源檔名（如 `影片.srt`、`影片_subtitled.mp4`）。想集中輸出到固定資料夾，可在「自動化輸出」的「輸出資料夾」指定。同名檔不會被覆蓋，會自動加上 `(1)` 流水號。

**Q：把檔案拖到 exe 圖示上沒有反應？**
A：拖曳執行採用「自動化輸出」記憶的設定，請先開啟程式在「自動化輸出」勾選至少一種匯出格式（或燒錄），關閉程式後再拖曳。處理需要時間（轉錄與燒錄），完成後才會跳出結果視窗。

**Q：審片助手的「精彩片段」是怎麼判定的？標太多／太少怎麼辦？**
A：綜合四種訊號評分——說話音量能量、語速、情緒詞（哇、太扯、wow…）與驚嘆句，達門檻即標記。標太少請到「偵測設定」把**精彩敏感度**調高（如 1.5），標太多就調低（如 0.7）；也可在**自訂情緒詞**加入自己頻道常用的口號與梗詞，讓判定更貼合內容。設定會自動記憶。

**Q：同一支影片轉錄過了，換個功能又要重新等辨識？**
A：v1.4.0 起內建轉錄快取：同一檔案且轉寫設定相同時自動重用先前結果（例如審片分析完再一鍵上字幕，第二次瞬間完成）。快取存於程式資料夾的 `transcribe_cache/`，自動限量清理；不需要時可在「轉寫設定」取消勾選「重用轉錄快取」。

**Q：輸出的直式短片人物不在畫面中間？**
A：「裁切」版式預設焦點 0.5（畫面正中）。人物偏左調小（如 0.3）、偏右調大（如 0.7）後重新輸出；或改用「模糊背景」版式保留完整畫面。

**Q：響度正規化該用什麼目標值？**
A：一般影片用預設 **-14 LUFS**（YouTube 標準）即可。想在正規化後仍略高於平台基準，可用 -13～-11；Podcast 類口說內容常用 -16。設定會記憶，不需每次調整。

**Q：轉錄結果在同一時間點出現多句重複字幕？**
A：這是 Whisper 遇到靜音或背景音樂時的已知現象（幻覺迴圈），v1.4.0 已加入三層自動去重防護。若仍遇到，可回報 issue 並附上來源音訊特徵（如長靜音、純音樂段）。

**Q：動態字幕（卡拉OK／單字彈出）選了卻沒有效果？**
A：動態字幕需要逐字時間軸，只在「模式一：音訊轉錄」產生的字幕上生效；手動字幕、文字稿對齊或編輯過文字的句子會自動退回一般整句顯示。另外效果只出現在**燒錄影片與 ASS 匯出**——「即時字幕預覽」與 SRT／VTT 輸出維持整句。若整支影片都沒有效果，請確認字幕是本次以模式一生成的（重新按「開始生成字幕」即可）。

**Q：尋找取代會改到時間軸嗎？改錯了怎麼辦？**
A：尋找取代只改文字，時間軸完全不動。「全部取代」前可先用「找下一個」逐句檢視命中的句子；若取代錯了，把「尋找」與「取代為」兩欄對調再全部取代一次即可還原。

**Q：審片助手輸出的 EDL 怎麼用？**
A：在 Premiere Pro 選「檔案 → 讀入」、DaVinci Resolve 選「File → Import → Timeline」載入 `.edl`，再連結原始素材，時間軸就是保留段落的順剪，可直接開始精剪。

**Q：粗剪影片／精彩合輯輸出後聲音或畫面不同步？**
A：粗剪採重新編碼（libx264＋AAC）確保剪點精準，一般不會不同步；若來源影片編碼特殊，建議改用 EDL 進剪輯軟體處理。
