# v2.3.0 新增功能介紹：螢幕畫面翻譯

> 這份是給**正在用 v2.1.0** 的使用者看的——v2.1.0 之後，v2.2 與 v2.3 兩
> 次大更新一起以正式版推出，所以更新上來時兩版的改動會一起到齊。v2.2 那一
> 段在文末，完整說明見 [`WHATS_NEW_2.2.md`](WHATS_NEW_2.2.md)。

---

## 一句話

**框選螢幕上任何一塊畫面，在這台電腦上把裡面的字認出來，確認過再翻譯；
也可以直接朗讀或複製。**

遊戲對話框、影片裡燒死的字幕、圖片、PDF 掃描檔、選不到字的軟體介面——
以前這些字只能自己一個一個打進翻譯網站，現在框一下就好。

---

## 為什麼要做這個

「即時查譯」只翻**選得到的字**；v2.1.0 的「監聽剪貼簿」把範圍擴大到**複
製得到的字**。但使用者真正卡住的，常常是畫面上那些**連選都選不起來**的字
——遊戲、影片、圖片。這一版補上最後這一塊。

---

## 怎麼用

1. 開〔即時查譯〕，查譯頁最上面多了一列：〔框選螢幕翻譯〕〔翻譯辨識結果〕
   〔熱鍵 Ctrl+Alt+F8〕。
2. 按〔框選螢幕翻譯〕。**第一次用**會先跳出「安裝文字辨識」視窗——引擎
   約 50～60 MB、語言檔每個 2～4 MB，裝到程式自己的資料夾，不需要管理員
   權限，只要裝一次。預設勾好英文、日文、繁體中文。
3. 面板會先收起來、整個畫面變暗。**按住左鍵拖出要翻譯的範圍，放開就開始
   辨識**。按 Esc 或右鍵取消。
4. 一到三秒後，認出來的字出現在「原文」框。**原文框可以直接改**——辨識偶
   爾會認錯字，改好再送。
5. 按〔翻譯辨識結果〕送出翻譯。譯文、「值得學的關鍵詞」、生字本都和原本
   的即時查譯一樣。

辨識語言不用選：程式會用你裝了的語言（英、日、繁中、簡中、韓）逐一試，
挑認得最有把握的那一個。英文畫面第一個就認到了，不會多等。

### 朗讀與複製

「原文」下方多了一列：**朗讀**〔原文〕〔譯文〕〔停止〕、**複製**〔原文〕
〔譯文〕。

- **不需要 API 金鑰**，也不連網——用的是電腦內建的語音。
- 太長的內容會念到句子結束的地方為止（上限 1000 字），狀態列會說省略了
  幾個字。
- 複製進剪貼簿的內容不會被「監聽剪貼簿」當成新複製的東西再翻一次。

### 熱鍵

勾選〔熱鍵 Ctrl+Alt+F8〕之後，**在任何程式裡按 Ctrl+Alt+F8 都會直接開始
框選**，不必先切回本程式。勾選會記住，下次開程式自動生效——不用先打開查
譯面板。

- 預設**關閉**，要自己勾。
- 選 Ctrl+Alt+F8 是為了避開剪輯與文書軟體常用的快捷鍵，不會搶走你在其他
  軟體裡的操作。
- 如果這組鍵已經被別的程式佔走，會退回「只在本程式視窗內有效」，並且在
  面板上寫清楚是哪一組鍵、為什麼——不會按了沒反應卻什麼都不說。

## 你的畫面不會被傳出去

這個功能碰得到你螢幕上的任何東西，所以規則訂得很保守——**寧可漏翻，也不
要誤送**：

- **只截你框的那一塊**，只在你按下去的時候截**一次**。不會自動截、不會在
  背景截、不會連續截。
- **辨識在這台電腦上跑**。截下來的圖認完字就刪掉，不會存在任何地方，也不
  會被送出去。
- **送翻譯之前一定先給你看**原文框裡是什麼，你按了〔翻譯辨識結果〕才送。
- 認出來的內容**像密碼或金鑰**（包括「密碼：xxxx」這種連欄位名稱一起框進
  來的）一律不送；仍然可以在本機朗讀或複製。
- 畫面上**讀不到字**（例如框到一塊花紋）時不送，不會把一串亂碼拿去翻。

**翻譯本身**跟即時查譯一樣呼叫 OpenAI API，需要 API 金鑰、會計費（短句約
千分之一美元）。辨識與朗讀都在本機、不需要金鑰。

## 做不到的事

- **全螢幕獨佔模式的遊戲抓不到**。會抓到一整塊同色，程式會直接告訴你：把
  遊戲改成「視窗化」或「無邊框視窗」再試。
- **不做連續即時翻譯**。每框一次翻一次，不會自動追著畫面跑。
- **只支援主螢幕**。接了兩個以上螢幕時，框選層只蓋在主螢幕上。
- 字很小、背景很花、或是手寫字時，辨識準確度會明顯下降。原文框可以改就是
  為了這個。

## 老實說：哪些在 Windows 上還沒親眼看過

開發是在 Linux 上做的。「框選 → 截圖 → 辨識 → 顯示 → 翻譯」這一整條路在
Linux 的虛擬螢幕上真的走過（畫一行字、真的截圖、真的辨識出來），但下面這
些是 Windows 專屬的部分，**這一版還沒有在 Windows 上實際確認過**：

| 項目 | 狀態 | 萬一不行會怎樣 |
|---|---|---|
| 一鍵安裝文字辨識引擎（下載官方安裝檔） | 未實際確認（語言檔的下載已確認） | 下載或安裝失敗時會說明怎麼手動安裝 |
| Windows 的螢幕截圖 | 未實際確認 | 每一步失敗都有看得懂的訊息，不會送一張黑圖去辨識 |
| 高解析度縮放（125%、150%） | 已寫好換算，未實際確認 | 框到的位置可能會偏——**遇到請回報**，附上你的縮放比例 |
| 框選時畫面變暗的效果 | 未實際確認 | 設不起來時只是不透明，照樣框得到 |
| 全域熱鍵 Ctrl+Alt+F8 | 未實際確認 | 退回只在本程式視窗內有效，面板上會寫原因 |
| 朗讀（Windows 內建語音） | 未實際確認 | 狀態列會說念不出來的原因，不影響翻譯 |

以上任何一項在你的電腦上不正常，**請回報**：遇到什麼畫面、縮放比例多少、
是哪個程式。

## 從 v2.1.0 更新上來的話：v2.2.0 的改動

v2.2 只有一個主題：**健檢中心搬進主視
窗**——不再另外開視窗，點〔③ 健檢中心〕頁籤就是它；18 項檢查左右並排、
預設尺寸下一次全看得到；字幕每次健檢前向主視窗現拿，改完錯字切回來重跑，
報告講的就是新句子。

詳細說明與實測數字見 [`WHATS_NEW_2.2.md`](WHATS_NEW_2.2.md)。

## 沒有變的事

即時查譯原本的選字即翻、監聽剪貼簿、關鍵詞解說、生字本匯出，行為一項都沒
變；轉寫、字幕、健檢、輸出這些主流程完全沒動；命令列工具沒動。
