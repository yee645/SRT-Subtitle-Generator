# 剪輯器版面改版（E 系列）

> 2026-11-26 使用者的新目標：「將剪輯軟體做得更符合市面上主流的影音編輯軟體，如剪映、adobe premiere，
> 並將現有的功能合併進去，並將 UI 設計做好一點」。
>
> 這份文件是 E 系列的工作清單與設計規格。做法沿用 3.0 的經驗：**新版面跟現在的四頁籤並行**，
> 先用開關打開（`--editor`），每一階段都能用、都有測試；追平之後才切成預設、發版。

## 一、現在哪裡不像剪輯軟體（2026-11-26 截圖盤點）

| 問題 | 現在 | 主流剪輯軟體（剪映專業版、Premiere） |
|---|---|---|
| 工作流程被頁籤切開 | ①素材與剪輯、②字幕、③健檢、④輸出四頁，剪片要在①②之間來回切 | **單一工作區**：素材、預覽、屬性、時間軸同時看得到 |
| 像表單，不像剪輯器 | 一排排同樣大小的灰色按鈕、整段說明文字；時間軸只佔下方一小條 | 預覽與時間軸是主角；工具是圖示按鈕，說明放在滑鼠停留的提示裡 |
| 沒有屬性面板 | 樣式、畫面調整、配樂設定都另開小視窗；選了素材要到一行小字裡改屬性 | 右邊**屬性面板跟著選取變**：選字幕顯示文字與樣式、選畫面顯示畫面調整、選音樂顯示音量 |
| 沒有素材庫 | 一次只開一支影片；B-roll／音樂用「加入畫面…」選檔直接放上去 | 左上**素材庫**：匯入一批檔案、看縮圖，再拖到時間軸 |
| 匯出藏起來 | 在④頁籤，還分「照剪點輸出」「輸出多軌」「完成輸出」三個地方 | 右上角一顆醒目的〔匯出〕，一個對話框搞定 |
| 時間軸工具不完整 | 拉遠／拉近／整支是三顆文字按鈕；沒有分割、沒有吸附開關、沒有軌道標頭 | 時間軸上方一列工具：復原、重做、分割、刪除、吸附、縮放滑桿；左邊軌道標頭（鎖定、靜音、隱藏） |
| 視覺 | Fusion 預設外觀，淺色是系統灰；元件間距不一、沒有視覺層次 | 深色為主、一個強調色、面板之間有層次、統一的圓角與間距 |

### 頂列與匯出

- 左：程式名稱＋專案名稱（未存檔加 •）。〔開專案〕〔存專案〕放在專案名稱的選單裡。
- 右：〔轉寫與金鑰〕〔即時查譯〕〔深淺色〕三顆圖示按鈕，最右邊強調色的〔匯出〕。
- 〔匯出〕開一個對話框，合併現在的四個出口：匯出字幕檔、燒錄、照剪點輸出、輸出多軌，以及④的「完成輸出」、品牌套版、多語字幕包。

### 間距、圓角、字級

- 間距：4／8／12／16／24，面板內距 12，面板之間的縫 2（露出 `bg.window`）。
- 圓角：按鈕與輸入框 6、面板 8、時間軸上的塊 4。
- 字級：介面 13px、次要 12px、面板標題 13px 粗體、時間碼 等寬 14px。
- 按鈕三種：**主要**（強調色實心，一個畫面只有一顆，通常是〔匯出〕）、**一般**（`bg.raised`）、**圖示**（透明底，滑過出現 `bg.hover`）。

### 圖示

- 自己畫的 SVG（線條 1.6px、24 格），存在 `gui_qt/icons.py`，**不引用第三方圖示庫**（授權單純、打包不多帶檔案）。
- 依主題換色（把 `currentColor` 換成 `text.primary`／`accent`），停用時用 `text.muted`。
- 每顆圖示按鈕都要有提示文字（含快捷鍵）。

### E-1 做了什麼

- `python main.py --qt --editor` 打開剪輯器版面；不加 `--editor` 照舊是四頁籤（兩個都測）。
- `EditorWindow` 繼承四頁籤的 `MainWindow`：同一批面板與按鈕搬到新位置，**沒有另寫一份功能**；關視窗前的詢問、
  自動更新、一鍵安裝、設定存檔全部沿用。四頁籤外殼收起來（`legacy_central`）。
- 現有功能 → 新位置的對照表寫在程式裡（`gui_qt/editor.py` 的 `FEATURE_MAP`），測試逐項確認位置，並且反過來確認
  舊外殼與播放器面板裡**沒有剩下任何按鈕**（換成新元件的五顆列在 `REPLACED`）。
- 播放器與逐句校對原本「焦點在面板裡才有效」的復原／重做／存字幕／尋找，改成整個視窗都有效（同一組按鍵）。
- 左側面板切到智慧剪輯、健檢時自動拉寬（這兩個原本是整頁寬），切回來還原。
- 色票在 `subtitle/designtokens.py`，深淺兩套每一組字×底都量過 ≥ 4.5:1；圖示 34 個，全部自己畫。

**還沒做、記著**：審片助手、健檢、輸出面板裡的說明文字還寫「②字幕頁」「④」這些舊位置（E-7 一起改）；
時間軸本身的配色與工具（E-2）；屬性面板還是固定的幾段，不跟著選取變（E-3）。

### E-2a 做了什麼

- 時間軸（四頁籤與剪輯器共用的 `gui_qt/timeline.py`）的顏色全部改取色票：字幕塊 `track.subtitle`、波形與音樂
  `track.audio`、疊加 `track.overlay`、剪點 `track.cut`、播放頭 `accent`、接縫 `warning`、列底 `bg.raised`、
  縫 `bg.panel`。新增 `track.text`（方塊上的字，深淺兩色都是 `#0b0c0f`），四組「字 × 軌道色」都量過 ≥ 4.5:1。
  timeline.py 裡不再有寫死的色碼（測試掃原始碼）。
- 列高改成每個時間軸自己的（`row_layout()`）：四頁籤照舊（`ROW_Y`、`TOTAL_H` 不變），剪輯器版面用 `TALL_HEIGHTS`
  （字幕 44、素材軌 32…）。
- 剪輯器版面左邊多一欄軌道標頭（`TrackHeader`）：名稱＋軌道色條，滑過去的提示寫原本攤在空列上的說明；列上不再寫說明。
- 沒開影片時，時間軸只顯示一句話＋〔開啟影片…〕（同媒體區那顆的動作）。
- 字幕塊、素材塊放不下時尾巴加「…」。
- hallmark 審查（2026-11-26）列的五點：色碼寫死、沒有軌道標頭、空狀態、截字、淺色時間軸太灰，都在這一段處理了。

**還沒做、記著**：工具列的新動作（E-2b）；疊加／音樂素材的分割（素材軌還沒有復原紀錄，跟 E-3 的屬性面板一起做）。

### E-2b 做了什麼

- 〔分割〕（Ctrl+B）：在播放頭把字幕切成兩句。切的是選取的那句（播放頭要在它裡面），不然是播放頭底下那句；
  字照時間比例分，附近有換行切在換行、其次標點或空白之後（`subtitle/cueedit.py` 的 `split_cue`／`split_text`／
  `cue_at`）。兩段都至少 0.1 秒，切不了在狀態列講原因。復原一步合回原句（`EditHistory.record_split`）。
- 〔刪除〕（Delete）：取代原本只刪素材的〔刪除選取〕（`REPLACED`），刪時間軸上最後選的字幕或素材；沒選東西不能按。
- 〔吸附〕開關：關掉之後拖字幕、素材都不貼播放頭與鄰句的邊（`TimelineView.snap_enabled`）。
- 縮放滑桿（對數刻度）放在〔拉遠〕〔拉近〕中間，跟按鈕、Ctrl＋滾輪、〔整支〕同步。
- 順手修的錯：逐句校對的編輯框在句子換了位置（分割、刪除、復原）之後，會把沒改過的舊字寫到別句上；改成只在真的
  改過字時套用（四頁籤也有這個隱患，`test_qt_cuelist.py` 加了回歸測試）。

**還沒做、記著**：疊加／音樂素材的分割（素材軌還沒有復原紀錄，跟 E-3 一起）；J／K／L、逐格、Ctrl+=／Ctrl+-／Shift+Z
（E-6 快捷鍵）。

## 六、每一階段都要做的事

- 現有測試不能放寬；搬過去的功能，舊介面的測試照樣跑。
- 新版面的每個區塊都在深淺兩色截圖、用 Read 看過。
- 每一階段在 PR 裡列「現有功能 → 新位置」對照，沒搬的寫明在哪一階段搬。
- 用了 hallmark 設計技能的話，拿它把設計基準與截圖檢查一輪，結果記在這裡（E-2a 起每一段都做；第一輪的結論見〈E-2a 做了什麼〉）。
