# 剪輯器版面改版（E 系列）

> 2026-11-26 使用者的新目標：「將剪輯軟體做得更符合市面上主流的影音編輯軟體，如剪映、adobe premiere，
> 並將現有的功能合併進去，並將 UI 設計做好一點」。
>
> 這份文件是 E 系列的工作清單與設計規格。做法沿用 3.0 的經驗：**新版面跟現在的四頁籤並行**，
> 先用開關打開（`--editor`），每一階段都能用、都有測試；追平之後才切成預設、發版。

## 一、現在哪裡不像剪輯軟體（2026-11-26 截圖盤點）

| 問題 | 現在 | 主流剪輯軟體（剪映專業版、Premiere） |
|---|---|---|
| 工作流程被頁籤切開 | ①素材與剪輯、②字幕、③健檢、④輸出四頁，剪片要在①②之間來回切 | **單一工作區**：素材、預覽、屬性、時間軸同時看得到 |
| 像表單，不像剪輯器 | 一排排同樣大小的灰色按鈕、整段說明文字；時間軸只佔下方一小條 | 預覽與時間軸是主角；工具是圖示按鈕，說明放在滑鼠停留的提示裡 |
| 沒有屬性面板 | 樣式、畫面調整、配樂設定都另開小視窗；選了素材要到一行小字裡改屬性 | 右邊**屬性面板跟著選取變**：選字幕顯示文字與樣式、選畫面顯示畫面調整、選音樂顯示音量 |
| 沒有素材庫 | 一次只開一支影片；B-roll／音樂用「加入畫面…」選檔直接放上去 | 左上**素材庫**：匯入一批檔案、看縮圖，再拖到時間軸 |
| 匯出藏起來 | 在④頁籤，還分「照剪點輸出」「輸出多軌」「完成輸出」三個地方 | 右上角一顆醒目的〔匯出〕，一個對話框搞定 |
| 時間軸工具不完整 | 拉遠／拉近／整支是三顆文字按鈕；沒有分割、沒有吸附開關、沒有軌道標頭 | 時間軸上方一列工具：復原、重做、分割、刪除、吸附、縮放滑桿；左邊軌道標頭（鎖定、靜音、隱藏） |
| 視覺 | Fusion 預設外觀，淺色是系統灰；元件間距不一、沒有視覺層次 | 深色為主、一個強調色、面板之間有層次、統一的圓角與間距 |

### 左側面板（左邊圖示列切換）

| 圖示 | 內容 | 來自 |
|---|---|---|
| 媒體 | 素材庫：匯入影片、圖片、音樂，縮圖格狀；拖到時間軸；〔音訊轉影片〕〔批次處理〕 | ①素材準備、播放器的〔開啟影片〕〔加入畫面…〕〔加入音樂…〕 |
| 字幕 | 〔生成字幕〕〔匯入字幕〕＋逐句清單（改文字、新增、刪除、尋找取代、翻譯） | ②的生成字幕、載入字幕、逐句校對 |
| 智慧剪輯 | 審片助手：分析、段落清單、粗剪、精彩合輯、章節、封面候選、直式短片 | ①審片助手 |
| 健檢 | 18 項檢查與一鍵修復、發佈文字與章節、封面圖、系列一致性 | ③健檢中心 |

### 屬性面板（跟著選取變）

| 選了什麼 | 顯示 | 來自 |
|---|---|---|
| 一句字幕 | 文字（可直接改）、時間、**字幕樣式**（字型、大小、顏色、外框、位置、動態效果） | 逐句校對的編輯框、〔字幕樣式…〕視窗 |
| 主片段 | 畫面調整（亮度、對比、飽和度、裁切、旋轉、翻轉）、代理檔 | 〔畫面調整…〕視窗、〔編輯用代理檔〕 |
| 疊加素材 | 位置、帶聲音、畫面調整 | 素材軌那一行的屬性、〔調畫面…〕 |
| 音樂 | 音量、循環、講話時壓低、〔配樂設定〕 | 素材軌那一行、〔配樂設定…〕 |
| 剪點 | 停用、範圍、接縫（硬切／溶接／黑場、長度） | 剪點列、接縫選單 |
| 什麼都沒選 | 專案：影片資訊、剪點種類、預覽剪後 | 剪點選單 |

### 頂列與匯出

- 左：程式名稱＋專案名稱（未存檔加 •）。〔開專案〕〔存專案〕放在專案名稱的選單裡。
- 右：〔轉寫與金鑰〕〔即時查譯〕〔深淺色〕三顆圖示按鈕，最右邊強調色的〔匯出〕。
- 〔匯出〕開一個對話框，合併現在的四個出口：匯出字幕檔、燒錄、照剪點輸出、輸出多軌，以及④的「完成輸出」、品牌套版、多語字幕包。

### 間距、圓角、字級

- 間距：4／8／12／16／24，面板內距 12，面板之間的縫 2（露出 `bg.window`）。
- 圓角：按鈕與輸入框 6、面板 8、時間軸上的塊 4。
- 字級：介面 13px、次要 12px、面板標題 13px 粗體、時間碼 等寬 14px。
- 按鈕三種：**主要**（強調色實心，一個畫面只有一顆，通常是〔匯出〕）、**一般**（`bg.raised`）、**圖示**（透明底，滑過出現 `bg.hover`）。

### 圖示

- 自己畫的 SVG（線條 1.6px、24 格），存在 `gui_qt/icons.py`，**不引用第三方圖示庫**（授權單純、打包不多帶檔案）。
- 依主題換色（把 `currentColor` 換成 `text.primary`／`accent`），停用時用 `text.muted`。
- 每顆圖示按鈕都要有提示文字（含快捷鍵）。

### E-9f 做了什麼

- 記著：Qt 的樣式表沒有「只在鍵盤操作時顯示」（:focus-visible），用滑鼠按一般按鈕之後框也會留著，直到焦點移走；
  圖示按鈕（QToolButton）本來就不搶滑鼠焦點，不受影響。
- 測試 `tests/test_qt_focus_ring.py`（深淺兩色）：四種按鈕有焦點時框是該有的顏色、沒焦點時沒有；有焦點時大小不變、
  裡面的字與圖示沒有移動。

### E-9l 做了什麼

- 剪輯器把很多按鈕改成只有圖示（字放進提示），但沒有設 accessibleName：轉寫與金鑰、即時查譯、介紹、深淺色、復原、重做、
  拉遠、拉近、整支、上一格、播放、下一格、專注預覽，共 13 顆，螢幕閱讀器只念得出「按鈕」。
- `_IconNames`：只有圖示的按鈕用提示的第一段（`accessible_label`：「：」「（」之前）當名字、整段提示當說明；
  提示換了（播放／暫停、切換深淺色）名字跟著換。有字的按鈕不動（螢幕閱讀器念字）；收起來的舊外殼不動；四頁籤不動。
- 檢查 Tab 順序：頂列 → 左邊圖示列 → 左側面板 → 預覽 → 屬性面板 → 時間軸 → 狀態列，再繞回頂列，順序合理，沒有改。
- 測試 `tests/test_qt_icon_names.py`：`accessible_label` 的切法；每一顆只有圖示的按鈕都有名字與說明；切換深淺色、
  播放變暫停時名字跟著換；有字的按鈕不動。
- 順手修：Qt 全套偶爾印出一個 Traceback——背景量影格率（`_FpsProbe`）量好時視窗已關（物件已刪），emit 丟
  `RuntimeError: Signal source has been deleted`。看時機，main 也會發生。改成物件已刪就安靜丟掉結果；
  測試 `tests/test_qt_fps_probe_closed.py`（拿掉修正會抓到那個 RuntimeError）。

### E-9m 做了什麼

- 截圖時發現：開窗後狀態列右下角的〔改用四頁籤版面…〕框著強調色——Qt 把焦點交給第一顆能拿焦點的元件，剛好是它。
  空白鍵還是播放（視窗快捷鍵優先），但一開窗最顯眼的是一顆角落按鈕，Tab 也從視窗最後面開始走。
- 改成照主流剪輯軟體把焦點放在時間軸區：剛開窗還沒有片子，是空狀態的〔開啟影片…〕（正好是下一步）；
  開了片子它藏起來，Qt 照焦點順序交給時間軸本身。焦點在別處（例如字幕表）時開片子不去搶。
- 測試 `tests/test_qt_initial_focus.py`：開窗焦點在〔開啟影片…〕、不在角落那顆；空白鍵是播放、沒按到按鈕；
  開了片子焦點換到時間軸；焦點在字幕表時開片子不動它。
