# 3.0.0 新增功能介紹：新介面（真的播放器與時間軸）

> 這份是給**正在用 v2.3.6** 的使用者看的——v2.3.6 是 3.0.0 之前最後一個正式版，所以更新上來時，
> 中間所有的改動會一次到齊。這些改動幾乎都在**新介面**裡；一般版（原本那個視窗）只修過錯，功能沒有變。

---

## 一句話

**字幕疊在真的影片畫面上邊播邊改，下面一條時間軸看得到縮圖、波形、字幕與要剪掉的地方；
一般版的功能全部搬過去了。**

以前的「預覽」是畫出來的假畫面，剪停頓、剪重複片段是看不到剪哪裡的盲剪。3.0 換成 Qt 介面之後，
這兩件事終於做得到：看著畫面改字幕、看著時間軸決定剪哪裡。

---

## 怎麼拿到

| 你現在用的是 | 怎麼做 |
|---|---|
| 一般版 exe（`SRT-Subtitle-Generator.exe`），開著自動更新 | 照常更新到 3.0（v3.0.1 起；v3.0.0 只發成預發佈、沒有轉正）。重開之後會跳「3.0 新介面」：按〔下載並安裝新介面〕，它會裝在 exe 旁邊的 `SRT-Subtitle-Generator-Qt` 資料夾，設定、生字本與一鍵安裝的工具會**複製**一份過去，裝好按〔開啟新介面〕。 |
| 還沒裝過 | 到 [Releases](../../../releases) 下載**最新一版**的 `SRT-Subtitle-Generator-Qt-v<版本>-win64.zip`（3.0.1 起；不要用 v3.0.0 那一份，見下面「已知的限制」），解壓到任何資料夾，執行裡面的 `SRT-Subtitle-Generator-Qt.exe`。免安裝。 |
| 從原始碼跑 | `pip install PySide6` 之後 `python main.py`（3.0.0 起預設就是新介面；要一般版加 `--tk`）。 |

- 新介面是一整個資料夾（不是單一 exe）：zip 約 **56 MB**，解開約 **129 MB**（2026-11-23 Windows CI 實測）。
  做成資料夾是因為啟動快得多；一般版的單一 exe 每次開都要先自己解壓。
- **一般版不會被刪掉**，照樣可以用、照樣會自動更新。從一般版裝新介面時設定是複製過去的，之後兩邊各自一份。
- 不想裝：提示視窗勾「不再提醒」就不會再問；之後想裝，到 Releases 下載 zip 就好。

**會送出去的**：查版本與下載 zip 都是向 GitHub 的一般連線請求，不送任何檔案、字幕、設定或帳號資訊。

## 新介面多了什麼

### 字幕疊在真的影片畫面上

②字幕頁的播放器邊播邊顯示字幕，字型、大小、外框、位置照你的樣式畫——跟燒錄出來的畫面比對，
位置差 0～3 像素；逐字動態字幕（卡拉 OK、逐字跳出）也照實預覽，跟燒錄差 4 像素內。
改樣式（②〔字幕樣式…〕）立刻在畫面上看到。

### 時間軸

縮圖條、聲音波形、字幕塊、播放頭排成一條：

- 點一下跳過去；拖字幕塊的左右邊改時間、整句拖、選好用 ← ／ → 微調；全部可以復原。
- 5 分鐘的片子：波形約 1.5 秒、720p 縮圖 150 張約 1.2 秒算好，之後讀快取幾乎不用等。
- 1080p 以上的片子自動做一份低解析度的代理檔來剪：跳轉從最慢 0.4 秒變成 0.01 秒；
  輸出、縮圖、波形照樣用原檔。

### 剪點看得見

剪停頓、剪重複片段、審片助手建議剪掉的段落，直接畫在時間軸上：

- 每一段可以單獨停用、拖邊調範圍；
- 勾〔預覽剪後〕播放時跳過剪掉的部分，聽聽接起來順不順；
- 接縫可以選硬切、溶接或黑場；
- 〔照剪點輸出…〕輸出剪好的影片，字幕跟著對齊。

### 多段素材與多軌

時間軸上可以加畫面（B-roll 影片、圖片）與音樂：拖位置會吸附、拖邊修頭尾；
音樂可以循環、調音量、遇到說話自動壓低（〔配樂設定…〕）；子畫面可以擺位置。
播放器上照輸出的位置疊出來預覽。跟剪點一起輸出——畫面跟著剪、字幕跟著對齊；
切 30 段的片子輸出時間從 79 秒縮到 33 秒。

### 畫面調整即時預覽

亮度、對比、飽和度、裁切、旋轉、翻轉，調了播放器上馬上看到；主片與疊加的素材都能調。

### 專案檔

整條時間軸（剪點、素材、樣式、字幕）存成 `.srtproj`，下次〔開專案…〕接著做；
搬過資料夾、找不到的檔案會列出來。

### 在程式裡更新

新介面有新版時，頁籤上方會出現提示：按〔下載並安裝〕，準備好之後關掉程式時自動換上新版並重新開啟，
設定、生字本與一鍵安裝的工具一起帶過去；換不過去就照樣開回原本那一版。
（這一段在 Windows 上實測過：中文、空白、單引號的路徑，程式還開著時會等它關掉才換。）

## 一般版的東西在新介面的哪裡

第一次打開新介面會跳「新介面導覽」，就是這張對照表（狀態列右邊〔新介面導覽…〕隨時可以再打開）。
最常找的幾個：

| 一般版 | 新介面 |
|---|---|
| 左欄「轉寫設定」（模型、金鑰、提示詞） | 頁籤列右上角〔轉寫與金鑰…〕 |
| 斷句設定、習慣設定、字幕視覺調整 | ②〔字幕樣式…〕（三塊在同一個視窗） |
| 〔開始生成字幕〕 | ②播放器上方〔生成字幕…〕 |
| 字幕清單、尋找取代、翻譯 | ②右邊的逐句校對 |
| 剪停頓、剪重複片段 | ②時間軸上方的「剪點」選單（看得到剪哪裡，再〔照剪點輸出…〕） |
| 審片助手、音訊轉影片、批次一鍵完成 | ①素材與剪輯 |
| 健檢中心、系列一致性 | ③健檢中心 |
| 匯出、燒錄、〔完成輸出〕、品牌套版 | ④輸出與發佈 |
| 配樂助手 | ②時間軸加入音樂後，選取音樂軌按〔配樂設定…〕 |
| 即時查譯、框選螢幕翻譯 | 頁籤列右上角〔即時查譯…〕 |

四個頁籤的名稱與順序跟一般版一樣：① 素材與剪輯 → ② 字幕 → ③ 健檢中心 → ④ 輸出與發佈。

## 已知的限制（照實講）

- **只打包 Windows 版。** macOS、Linux 要從原始碼跑。
- **播放器的影音同步沒有在有音效卡的機器上量過**（開發環境與 CI 都沒有音效裝置）。影像解碼、字幕位置都量過；
  如果你發現聲音和畫面對不上，請回報，輸出的影片不受影響（輸出走 ffmpeg，不經過播放器）。
- 設定在關掉程式時才存回 `config.json`（只存這次改過的部分，一般版同時開著也不會互相蓋掉）。
- **v3.0.0 附的新介面 zip 用久了會崩潰**（打包時用的 Python 3.11 跟 PySide6 6.12.0 不合），v3.0.1 已經換掉；
  v3.0.0 只發成預發佈，自動更新不會拿到它。如果你手動下載過 v3.0.0 的 zip，換成新的一版。
- 遇到問題隨時可以回一般版：打包版是 `SRT-Subtitle-Generator.exe`，從原始碼跑是 `python main.py --tk`。
