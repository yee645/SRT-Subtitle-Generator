# 1.x → 2.0 對照表

v1.52 把主視窗從「11 顆工具列按鈕 ＋ 一整頁設定」改成四個階段頁籤。
**功能一個都沒有拿掉**，但老用戶的第一眼就是「不見了」——這份文件照
「我的某某功能呢」那個問法回答。

程式內也有同一張表：介面大改後第一次啟動會自動跳出「新版介面速覽」
（`gui/whatsnew_dialog.py`，可勾「不再顯示」）。這份是完整版。

---

## 新的四個階段

頁籤順序就是做一支影片的順序：

| 階段 | 做什麼 |
|------|--------|
| **① 素材與剪輯** | 選檔、匯入既有字幕、審片助手、剪停頓（依字幕）、剪重複片段 |
| **② 字幕** | 設定（左欄）＋主動作與字幕清單（中欄）＋樣式與即時預覽（右欄）。預設停在這裡 |
| **③ 健檢中心** | 爆音、音量、畫質、字幕品質、發佈資訊、封面、章節等健檢一次跑完 |
| **④ 輸出與發佈** | 「輸出」框（輸出設定＋完成輸出＋逐格式匯出）、成品加工、發佈資料 |

頂端有一條跨階段的**工作檔案列**，顯示目前影片與它的來歷
（「原始素材 訪談.mp4 → 粗剪 → 修復版（目前）」）與字幕句數。

## 改名的按鈕

| 1.x 舊名 | 2.0 新名 | 為什麼改 |
|---------|---------|---------|
| 自動跳剪停頓 | **剪停頓（依字幕）** | 原名看不出它吃的是字幕還是影片 |
| 重複片段偵測 | **剪重複片段** | 原名只說偵測，其實會剪 |
| 自動化輸出（一鍵完成用） | **輸出設定** | 「一鍵完成」這顆按鈕已經不存在，再指向它會找不到人 |
| 匯出與燒錄 | **只做單獨一件事** | 與同框的〔完成輸出〕差在「會不會問你存到哪裡」，這件事第一次寫在介面上 |

## 行為變了的地方（不只是搬家）

### 1. 〔一鍵完成〕拆成兩顆

1.x 的〔一鍵完成（生成＋匯出＋燒錄）〕會一路衝到底，等於**沒有校對的
機會就把錯字燒進影片**。

2.0 拆成並排的〔**開始生成字幕**〕＋〔**完成輸出（依輸出設定）**〕，中間
那段空白就是校對、健檢、翻譯的位置。不需要校對的話，連按兩顆，結果和
以前完全一樣。

**一次處理很多支影片**：選到兩個以上檔案時，動作列會自動多出
〔**批次一鍵完成**〕，行為與 1.x 的〔一鍵完成〕一致（批次本來就不會逐支
校對）。只選一個檔案時這顆不會出現。

### 2. 三個輸出面併成一個

1.x 的「同一個『輸出 SRT』概念出現三處、行為各不同」已終結。階段④現在
只有一個「輸出」框，由上而下就是決策順序：

1. **這次會輸出什麼**——例如「匯出 SRT＋燒錄硬字幕影片 → D:\成品」，
   勾選一改這句話立刻跟著變
2. **輸出設定**——勾格式、燒錄、響度正規化、輸出資料夾
3. **只做單獨一件事**——逐格式匯出按鈕，會另外問你存到哪裡

### 3. 產出會自動流回來

1.x 做出來的東西只跳一個訊息框報路徑就結束。2.0：

| 產出 | 2.0 的行為 |
|------|-----------|
| 粗剪／精彩合輯 | 問要不要設為「目前影片」，接手後直接上字幕／健檢 |
| 修復版（健檢中心） | 問要不要接手；接手後對象區同步換掉，再按〔開始健檢〕就是修復前後比對 |
| 燒錄版 | 記進世代鏈；問要不要接手（接著配樂、套版就吃這支） |
| 章節草稿 | 剪貼簿照舊，**另外**帶入 ④「發佈資料」 |
| 發佈包／封面候選 | 標題、說明欄、標籤、章節、候選圖自動流進 ④「發佈資料」 |

④「發佈資料」一顆〔**送健檢中心**〕就把整包填進健檢中心的對象區。

### 4. 兩個修剪視窗併成一個

〔剪停頓（依字幕）〕與〔剪重複片段〕現在是同一個「自動修剪」視窗的兩個
分頁。**兩顆入口都保留**，各自開到對應分頁——按下按鈕時想做的事是明確
的，先開通用視窗再叫你選分頁是多一步。

兩個偵測器的個性差異刻意保留：剪停頓動的是沒人講話的空檔（預覽後直接
輸出），剪重複片段動的是實際講話內容（**逐項勾選確認才剪**，因為刻意
重複的口號、報數測試麥克風都可能被誤判）。

## 設定與升級

- **設定檔沿用**，不必重設。勾選過的輸出格式、門檻、樣式組合都還在。
- 介面大改後第一次啟動會跳一次「新版介面速覽」，可勾「不再顯示」。
- 世代鏈（目前影片的來歷）**只記在這次開啟期間**，關掉程式就忘掉——
  鏈上全是絕對路徑，存起來之後你搬動或刪除檔案只會留下一串指向空氣的
  紀錄，比沒有更糟。

## 沒有變的事

- 所有核心能力（轉寫、對齊、手動字幕、斷句、樣式、燒錄、翻譯、多語
  字幕、審片、配樂、品牌套版、各項健檢與修復）一項不少。
- CLI（`cli.py`）的旗標全部沿用，沒有改名也沒有移除。
- `config.json` 的既有欄位沒有刪改，只有新增。
