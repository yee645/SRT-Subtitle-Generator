# 3.1.0 新增功能介紹：剪輯器版面

> 這份是給**正在用 3.0 新介面**的使用者看的。3.1 的改動都在新介面；一般版（原本那個視窗）沒有變。
> 還在用 v2.3.6、第一次裝新介面的話，先看 [3.0 新功能介紹](WHATS_NEW_3.0.md)，再回來看這份。

---

## 一句話

**新介面預設換成剪輯器版面：素材、預覽、屬性、時間軸放在同一個畫面，照剪映專業版、Premiere 的排法；
四頁籤的功能一個不少，想用回四頁籤，狀態列一顆按鈕就切回去。**

3.0 的新介面是四個頁籤（①素材與剪輯 → ②字幕 → ③健檢中心 → ④輸出與發佈），剪片要在①②之間來回切、
匯出藏在④。3.1 把同一批面板搬進一個工作區，再補上主流剪輯軟體都有、四頁籤沒有的東西。

---

## 怎麼拿到

| 你現在用的是 | 怎麼做 |
|---|---|
| 新介面（打包版），開著自動更新 | 有新版時提示列按〔下載並安裝〕，關掉程式時自動換上 3.1 並重新開啟。 |
| 一般版 exe | 照常更新；還沒裝新介面的話，照 3.0 的提示按〔下載並安裝新介面〕。 |
| 還沒裝過 | 到 [Releases](../../../releases) 下載最新一版的 `SRT-Subtitle-Generator-Qt-v<版本>-win64.zip`，解壓後執行 `SRT-Subtitle-Generator-Qt.exe`。 |
| 從原始碼跑 | `python main.py`（預設剪輯器版面）；`python main.py --tabs` 開四頁籤。 |

第一次開剪輯器版面會跳一次「剪輯器版面介紹」（版面、多了什麼、四頁籤的東西在哪、快捷鍵），頂列的〔?〕隨時再開。

## 版面

| 區塊 | 放什麼 |
|---|---|
| 頂列 | 程式名稱、專案名稱、〔開專案〕〔存專案〕……轉寫與金鑰、即時查譯、介紹、深淺色、**〔匯出〕** |
| 左邊 | 圖示列切換四區：**媒體**（素材庫、開影片、載入字幕、加入畫面與音樂、音訊轉影片、批次）、**字幕**（生成字幕、逐句校對）、**智慧剪輯**（審片助手）、**健檢** |
| 中間 | 預覽（字幕疊在真的影片畫面上）＋時間碼、上一格／播放／下一格、預覽放大、專注預覽 |
| 右邊 | **屬性面板**，跟著你選的東西變 |
| 下面 | 時間軸工具列（復原、重做、存字幕、分割、刪除、吸附、縮放）＋時間軸（畫面、聲音、字幕、剪點、疊加、音樂） |

四個區塊之間都能拖動調整大小；選單列（檔案、編輯、檢視、播放、說明）每一項都是畫面上的某一顆按鈕。

## 多了什麼

### 素材庫

左邊「媒體」最上面〔匯入素材…〕一次選好幾個影片、圖片、音樂：排成縮圖，寫著長度。拖到時間軸上想放的那一條、
那個時間就放上去（拖到疊加那一條放疊加軌、拖到音樂那一條放音樂軌；拖到別條就照種類放：影片與圖片放疊加、聲音放音樂）；
或選好按〔加到播放頭〕。
選一支影片按〔開成主片〕就是原本的「開啟影片」。

### 屬性面板跟著選取變

| 選了什麼 | 右邊顯示 |
|---|---|
| 什麼都沒選 | 專案：影片資訊、畫面調整、代理檔、剪點種類、預覽剪後、接縫轉場 |
| 一句字幕 | 這句的文字（直接改）、開始／結束時間（數字欄，改了照樣能復原）、〔字幕樣式…〕 |
| 一段疊加或音樂 | 那段的屬性：位置、帶聲音、音量、循環、講話時壓低、〔配樂設定…〕 |

### 在播放頭分割

〔分割〕或 **Ctrl+B**：選了字幕切字幕，選了疊加或音樂切那一段素材（圖片切長度、影片與音樂切進出點）。
素材軌的加、刪、拖、修頭尾、分割現在都能復原（3.0 只有字幕能復原）。

### 一個〔匯出〕搞定

右上角〔匯出〕（**Ctrl+E**）一個視窗，左邊目錄分四段：

1. **一鍵完成輸出**：照輸出設定一次做完（字幕檔＋燒錄）。
2. **剪好的影片**：照剪點輸出、輸出多軌（連同疊加、音樂、轉場、畫面調整）。
3. **字幕檔**：單獨匯出 SRT／VTT／ASS／TXT、多語字幕包。
4. **品牌套版**：片頭、片尾、浮水印。

進度與結果釘在最下面，捲到哪一段都看得到。

### 快捷鍵

| 按鍵 | 動作 |
|---|---|
| Space | 播放／暫停 |
| J／K／L | 倒退 1 秒／暫停／播放（再按 L 兩倍、四倍速） |
| ←／→ | 上一格／下一格（選了字幕時照舊微調那句） |
| Ctrl+B | 在播放頭分割 |
| Delete | 刪除選取（字幕或素材） |
| Ctrl+Z／Ctrl+Shift+Z | 復原／重做 |
| Ctrl+=／Ctrl+-／Shift+Z | 時間軸拉近／拉遠／整支 |
| Ctrl+S／Ctrl+Shift+S | 存字幕／存專案 |
| Ctrl+E | 匯出 |

打字的地方照常打字；焦點在清單、數字欄、滑桿時，←／→ 照它們自己的用法。

### 預覽

- 時間碼寫到百分之一秒（`00:01:23.45 / 00:05:00.00`），旁邊〔上一格〕〔下一格〕照影片的影格率走。
- **專注預覽**：左右兩個面板一起收起來，預覽變大；再按放回。選單「檢視」也可以只收一邊。
- **預覽放大** 2 倍、4 倍：看字幕邊緣、畫面細節，用滑鼠拖著看別的地方。

### 時間軸工具列

吸附開關（拖字幕、素材時貼到播放頭與鄰近的邊，關掉就自由拖）、縮放滑桿、刪除選取（字幕或素材都刪得掉）。

## 四頁籤的東西在哪裡

| 四頁籤 | 剪輯器版面 |
|---|---|
| ②〔開啟影片〕〔載入字幕〕〔加入畫面…〕〔加入音樂…〕 | 左邊「媒體」（也在選單「檔案」） |
| ②〔生成字幕…〕、逐句校對 | 左邊「字幕」 |
| ②〔字幕樣式…〕 | 左邊「字幕」，或選一句字幕後右邊屬性面板 |
| ②播放器、時間軸 | 中間預覽、下面時間軸 |
| ②剪點選單、預覽剪後、接縫、畫面調整、代理檔 | 右邊屬性面板（什麼都沒選的時候） |
| ②〔開專案〕〔存專案〕 | 頂列 |
| ①審片助手 | 左邊「智慧剪輯」 |
| ①〔音訊轉影片〕〔批次一鍵完成〕 | 左邊「媒體」 |
| ③健檢中心 | 左邊「健檢」 |
| ④輸出與發佈、②〔照剪點輸出…〕〔輸出多軌…〕 | 右上角〔匯出〕 |

面板裡原本寫「到②字幕頁」「照④的輸出設定」這類指路的字，在剪輯器版面裡會換成剪輯器的說法（「左邊「字幕」」「〔匯出〕」）；
四頁籤一字不差。

## 想用回四頁籤

狀態列右邊〔改用四頁籤版面…〕（選單「檢視」也有）：記進設定，**下次開啟**就是四頁籤，這次的視窗不變；
按了之後按鈕會寫「下次開：四頁籤版面（按此取消）」，再按一次取消。四頁籤的狀態列有〔改用剪輯器版面…〕換回來。
從原始碼跑可以直接加 `--tabs`（或 `--editor`），命令列優先於設定。

兩種版面是**同一套功能、同一份設定與專案檔**，隨時可以換。

## 已知的限制

- 只打包 Windows 版。
- 播放器的影音同步沒有在有音效卡的機器上量過（輸出的影片不受影響，輸出走 ffmpeg）。
- 預覽放大是放大畫面，不是用更高的解析度重新解碼：1080p 以上的片開了代理檔時，放大看到的是代理檔的畫質
  （右邊屬性面板取消〔編輯用代理檔〕就是原片）。

**會送出去的**：跟 3.0 一樣。版面、素材庫、介紹都在本機，不送任何東西出去。
